# art/refs/ — Visual Reference Library (internal only)

These images are **mood-board references for the team only — never shipped, never in the release zip** (Art Bible A-012).

## Convention

- File naming: `<element>-NN.<ext>` (lowercase, zero-padded) — e.g. `siphon-01.png`, `phantom-05.png`, `biome-04.png`
- Elements: `siphon · phantom · station · ship · biome · sky · neb · wthr · ui · map · menu`
- Slots and their sources are defined in [ArtBible.md §8](../../docs/ArtBible.md); add new slots there first (template in Appendix D)
- When a reference is placed: status in ArtBible §8 → `PLACED`, and any style decision it triggers is logged as `A-###` in ArtBible §11

## Rights

Every placed reference gets one line in `NOTES.md` (same folder): `file — source — rights status (fair-use internal / licensed / original)`.
